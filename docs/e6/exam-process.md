# Déroulement E6 2026 — repères pour le candidat

## Support de l'épreuve

L'épreuve repose sur **deux réalisations professionnelles** élaborées dans un environnement technologique conforme. Le dossier numérique comprend :
- une fiche descriptive pour chacune des deux réalisations ;
- les modalités d'accès aux éléments techniques ;
- les ressources matérielles et logicielles utilisées ;
- les schémas et documentations utiles.

Avant l'épreuve, la commission choisit l'une des deux réalisations et prépare une expression des besoins.

## Déroulement indicatif fourni par le rectorat

1. **30 min — préparation sur table** : analyse de l'expression des besoins, avec ordinateur pour consulter des ressources et éventuellement produire de la documentation.
2. **20 min maximum — entretien d'explicitation (E1)**.
3. **60 min — réalisation des objectifs identifiés en E1** dans l'environnement technologique.
4. **20 min maximum — recette de la solution (E2)**.

La commission peut étendre les questions à la maîtrise de l'environnement technologique, notamment si la demande formulée n'a pas pu être traitée.

## Ressources électroniques

Les ressources électroniques disponibles dans le centre, y compris des services en ligne, peuvent être utilisées, **sauf les services de communication synchrone ou asynchrone avec un tiers**. Les connexions peuvent être contrôlées.

Conséquence pratique : les documentations importantes du projet doivent être accessibles directement dans le dossier numérique/dépôt/environnement autorisé. Il ne faut pas dépendre d'une conversation avec une personne ou d'un assistant distant pendant l'épreuve.

## Expression des besoins

Le document de préparation prévoit notamment :
- circonstances de l'expression des besoins ;
- spécifications fonctionnelles de la production attendue ;
- production attendue ;
- documents fournis (schémas, diagrammes, captures si nécessaire) ;
- nature de la documentation professionnelle attendue : rapport de test, documentation technique, rapport d'incident, documentation utilisateur ou autre ;
- ajustements possibles après le premier entretien.

## Préparation EduGest

Le projet doit donc être suffisamment maîtrisé pour qu'une évolution circonscrite puisse être analysée puis réalisée en environ une heure : modification d'une règle métier, ajout d'un champ/écran, correction d'un bug, évolution d'une requête, adaptation d'une autorisation ou ajout/modification d'un test, selon la demande de la commission.
