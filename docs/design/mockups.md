# Maquettes R1 / R2

## Statut : À CONSTRUIRE ENSEMBLE

Les maquettes ne sont volontairement pas figées dans cette phase documentaire.

Méthode retenue :
1. choisir ensemble un écran ;
2. produire une première proposition ;
3. la tester visuellement et fonctionnellement ;
4. comparer plusieurs variantes si nécessaire ;
5. valider explicitement la version retenue ;
6. seulement ensuite l'ajouter comme référence de conception ;
7. la faire évoluer si les tests de développement montrent un problème.

Les spécifications fonctionnelles des écrans sont dans `docs/specifications/ui-specifications.md`. Elles définissent le contenu attendu sans imposer prématurément le design.

## Écrans à maqueter plus tard

R1 : connexion, tableau de bord/navigation, élèves, professeurs, classes/matières, évaluations/notes, absences/retards.

R2 : connexion, navigation desktop/mobile, tableau de bord, notes, absences/retards, emploi du temps, documents et messagerie.

Aucune image de maquette n'est considérée comme validée tant que le candidat ne l'a pas explicitement retenue.
