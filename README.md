# Projet BTS SIO - Gestion d'établissement scolaire

Ce dépôt contient la documentation et, à terme, le code source d'une application de gestion d'établissement scolaire. Le projet est conçu comme une réalisation professionnelle pour l'épreuve E6 du BTS SIO, option SLAM.

## Objectif

Proposer deux applications s'appuyant sur une API et une base de données communes :

- une application légère destinée aux élèves et aux professeurs ;
- une application lourde destinée au personnel administratif et aux administrateurs.

Le projet est actuellement en phase de cadrage fonctionnel. Aucun choix technologique ni code applicatif n'a encore été arrêté.

La documentation est versionnée avec le code. Toute décision importante (technologie, modèle de données, sécurité ou fonctionnalité ajoutée) doit être tracée dans la documentation avant ou avec son implémentation.
